# Blab Translation 视觉设计矩阵

## 1. 产品真相

| 项目 | 内容 |
| --- | --- |
| 产品 | AI 驱动的 Chrome 翻译扩展 |
| 核心用户 | 需要跨语言阅读网页、视频字幕、技术内容和漫画图片的人 |
| 真实能力 | 网页全文翻译、划词翻译、悬停翻译、输入框翻译、YouTube 字幕翻译、公式与代码保护、漫画图片翻译、自定义 API 与模型 |
| 品牌承诺 | 叭叭翻译，翻译一切 |
| 不能暗示 | Chrome 官方推荐、第一名、免费无限、支持尚未实现的长条 Webtoon、虚构评分或用户数量 |

## 2. Logo 探索

### L1 — Bubble Octopus / 对话泡泡八爪鱼

- 结构：八爪鱼头部就是一个圆润的对话气泡，八只短触手像正在展开的消息路径。
- 风格：极简扁平矢量、单一主轮廓、双色块。
- 优点：小尺寸识别最好；“叭叭”和“翻译”的含义直接。
- 风险：容易变成普通聊天软件，必须保留明确的八触手轮廓。

### L2 — Octo B / 负形字母 B

- 结构：八爪鱼头部内用两块圆润负形形成抽象字母 `B`，触手构成稳定底座。
- 风格：几何品牌标、成熟、略带科技感。
- 优点：能把 `Blab` 的首字母纳入识别，适合长期品牌化。
- 风险：负形不能像数字 8，也不能牺牲八爪鱼识别。

### L3 — Reach Everything / 万物触达

- 结构：八只触手末端各自形成小型对话点、字幕条、页面角或图像框，但整体仍是一个清楚的图标。
- 风格：更有动势的现代吉祥物标，平面为主，轻微层次。
- 优点：最能表达“翻译一切”。
- 风险：细节较多，必须控制到 128px 清楚、32px 不糊成一团。

## 3. 选型标准

1. 恰好八只触手，轮廓一眼可数。
2. 128px 清楚，缩至 32px 仍能认出八爪鱼和对话意象。
3. 不依赖文字就能成立，不使用随机语言符号。
4. 角色聪明、亲切、有行动感，但不幼儿化。
5. 能在深色与浅色背景上保持边界清楚。

### 主标选型

选择 `L1 — Bubble Octopus / 对话泡泡八爪鱼` 作为本轮主标。它同时具备清楚的对话气泡头部、恰好八条触手和最稳定的小尺寸轮廓，最适合 Chrome 工具栏、商店图标和宣传图中的角色锚定。`L2 — Octo B` 作为偏企业化的备选方向保留，`L3 — Reach Everything` 作为后续插画角色参考保留。

## 4. Chrome 宣传图

### C1 — Small Promo / 一眼记住品牌

- 尺寸：`440 × 280`
- 任务：在首页、分类页和搜索结果中建立第一眼识别。
- 构图：八爪鱼 Logo 占据约 40% 画面；品牌名与中文口号只保留两级；八条翻译路径形成环抱动势。
- 必显文字：`Blab Translation`、`叭叭翻译，翻译一切`
- 禁止：功能清单、微小 UI、虚假徽章、二维码。

### C2 — Marquee / 八路并行

- 尺寸：`1400 × 560`
- 任务：讲清楚“一个插件，接住不同载体中的表达”。
- 构图：中间是一页真实感浏览器场景，八爪鱼从浏览器边缘伸出八只触手，连接网页段落、划词浮层、输入框、视频字幕、公式、代码、漫画图片与模型设置；能力通过图形场景表达，不增加小字号标签。
- 必显文字：`Blab Translation`、`叭叭翻译，翻译一切`
- 文字控制：除品牌名与口号外不再添加正文。
- 禁止：伪造 Chrome 官方 UI 标识、虚构评分、难以核验的性能数字。

第一轮“触手连接八类能力”方案在两次生成中都出现 9 条触手，因此降级为未通过候选。

### C2b — Marquee / 完整主标 + 内容流

- 尺寸：`1400 × 560`
- 任务：保留完整八触手主标，同时用不依赖触手计数的方式表达“翻译一切”。
- 构图：左侧品牌名与口号，中间是网页原文—译文、字幕、代码和漫画组成的一条连续内容流，右侧是完整八触手主标。
- 必显文字：`Blab Translation`、`叭叭翻译，翻译一切`
- 禁止：让触手连接功能卡、增加小字号说明、伪造 Chrome 官方标识。

该方向通过最终验收，作为正式横幅交付。

### C3 — Feature Story / 翻译发生的一瞬间

- 尺寸：`1280 × 800`
- 任务：作为功能页、官网 Hero 或商店视觉补充，展示产品如何把混合内容自然转成译文。
- 构图：一张浏览器页面从左侧原文过渡到右侧译文，公式与代码保持不变；八爪鱼的触手分别照看字幕、漫画和划词浮层。
- 必显文字：`Blab Translation`、`网页 · 字幕 · 漫画 · 更多`
- 禁止：将概念图伪装成真实产品截图；不显示不存在的按钮或定价。

## 5. 一致性锁定

- 八爪鱼必须沿用选中 Logo 的头部比例、眼睛、触手形态和主色关系。
- 系列统一使用 Ocean Indigo、Coral Talk、Mint Signal、Deep Ink 和 Warm Shell。
- 每张图改变构图与叙事任务，但不改变角色身份。
- 所有成品独立生成、独立成立；不输出九宫格或一张图内的多个设计方案。
