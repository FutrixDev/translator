Blab Translation — 웹 페이지, PDF, 만화, 자막을 AI로 번역하세요.

웹 페이지, PDF, 전자책, 만화를 원문과 번역문을 나란히 놓고 읽고, YouTube는 이중 자막으로 보고, 어떤 이미지 속 글자든 번역하세요(OCR). 엔진은 셋 중에서: Chrome에 내장된 무료 기기 내 번역기, 믿을 수 있는 AI(클라우드 또는 로컬 모델, 본인의 키로), 또는 구독에 포함되어 키가 필요 없는 Blab Translation.

★ 이중 언어 웹 페이지
• 모든 문단 아래에 번역문. 서식, 링크, 이미지는 그대로.
• 번역문만 보고 싶다면? 키 하나: Alt+T.
• 본문 먼저 — 메뉴와 사이드바는 방해하지 않습니다. 페이지 전체는 Alt+W.
• 일부만 번역하고 싶다면? 영역을 가리키고 '여기만 번역'을 고르세요.
• iframe과 Shadow DOM 안까지 번역.
• 수식, LaTeX, 코드는 그대로. 논문도 읽기 편하게.
• 6가지 번역 스타일. 76개 언어. 오른쪽에서 왼쪽으로 쓰는 언어도 정확하게.

★ 멈출 때를 아는 자동 번역
• 이미 내 언어로 된 문장은 건너뜁니다 — 외국어 용어가 가득해도.
• 개인 메시지는 절대 자동 번역하지 않습니다.
• 사이트 규칙: 페이지의 어느 영역이든 가리켜 '여기는 번역 안 함', '원문 유지'를 지정. 엔진 고정, CSS 추가도 가능. 규칙은 브라우저 계정으로 동기화됩니다.

★ 레이아웃을 지키는 PDF 번역
• 이중 언어 또는 번역문만 있는 PDF. 그림, 수식, 레이아웃은 원래 자리 그대로.
• 로그인하면 매달 무료 페이지 제공.

★ 전자책과 문서
• Word, EPUB, TXT, Markdown → 이중 언어 또는 번역 파일.
• MOBI와 AZW3는 웹 리더에서 이중 언어로 읽기.

★ 이중 자막
• YouTube 자막 실시간 번역: 원문과 번역문을 두 줄로.
• 표준 자막 트랙이 있는 모든 HTML5 플레이어에서 작동.
• 플레이어 컨트롤 바에서 클릭 한 번으로 켜고 끄기.

★ 선택, 호버, 사전
• 텍스트를 선택해 번역 — 다시 번역, 엔진 전환, 복사, 소리 내어 읽기.
• 단어와 구문을 위한 내장 사전: 발음, 뜻, 예문, 어형 변화.
• 최근에 고른 언어가 언어 메뉴 맨 위에 표시됩니다.
• 보조 키를 누른 채 호버하면 그 문단만 번역.
• 페이지와 다른 언어로 입력 중인가요? 클릭 한 번으로 번역.

★ 만화
• 만화 페이지를 내 언어로 다시 그려 줍니다 — 원하면 채색까지.

★ 어떤 이미지 속 글자든(OCR)
• 스크린샷, 사진, 차트 등 어떤 이미지든 우클릭하면 그 안의 글자를 읽고 번역합니다.
• 이미지 전체도, 드래그로 지정한 영역만도 가능. 큰 이미지에 마우스를 올리면 '텍스트 인식' 버튼도 나타납니다.
• 기기에서 오프라인으로 인식: 영어, 그리고 화면 언어가 중국어·일본어·한국어라면 그 언어 — 다른 언어나 사진, 꾸민 글씨는 본인의 키로 비전 모델에 맡길 수도 있습니다.
• 구독하면 Blab Translation으로도 인식할 수 있으며, 키가 필요 없습니다.

★ 기본이 프라이버시
• 웹 페이지는 기본적으로 기기에서 번역됩니다. 텍스트가 컴퓨터 밖으로 나가지 않습니다.
• 본인의 AI 모델을 쓰면 텍스트는 본인의 키로 본인의 엔드포인트에 바로 전송 — 저희를 거치지 않습니다.
• Blab Translation은 처리를 위해 텍스트(이미지 인식은 이미지)를 저희 서버로 보내며, 아무것도 저장하지 않습니다.
• PDF, 문서, 만화 파일은 저희 서버에서 처리되며 7일 후 삭제됩니다.
• 오프라인 사전 팩은 저희 서버에서 내려받아 기기에 보관합니다. 무제한 저장공간 권한은 이를 위한 것입니다. 팩에서 단어를 찾을 때는 아무것도 전송되지 않습니다.
• 사용 분석 없음. 광고 추적 없음.
